# FORJA Development Pack

FORJA Development Pack is a Codex plugin that packages safe, evidence-based workflows for the FORJA SaaS.

## Scope

Version 1.0.0 will provide 12 focused skills for routing work, safe frontend changes, authentication and storage, Supabase migrations, releases, reviews, accessibility, performance, testing, documentation, incident response, and recovery.

The plugin is skills-only: it has no apps, MCP servers, or hooks. It does not grant permission to alter production systems, real data, or the FORJA SaaS outside the approved task scope.
